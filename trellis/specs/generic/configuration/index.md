# 配置管理

## 开发前检查清单

- [ ] 已确认该配置项的来源：环境变量 / 配置文件 / 数据库 / 运行时参数。
- [ ] 已确认该配置在哪些环境需要不同取值。
- [ ] 已确认缺失时的行为：报错退出，还是使用默认值。

## 可执行契约

1. **配置项必须有明确默认值或明确缺失行为**，二选一，不得两者皆无。
2. **密钥类配置不得进入版本库**，且不得出现在日志与错误消息中。
3. **配置读取集中在一处**：业务代码不直接读环境变量，统一由配置入口提供。
4. **启动时校验配置**：类型、范围、必填项在进程启动阶段完成校验，不留到运行期。
5. **环境差异必须显式**：不在代码里写「如果是生产则……」的分支，改由配置表达。
6. **配置变更必须可回滚**：新增必填项时提供向后兼容的默认值。

## 质量检查

- [ ] 新增配置项是否已加入示例配置与部署清单。
- [ ] 是否有硬编码的环境相关值（地址、端口、开关）。
- [ ] 缺失配置时的行为是否被测试覆盖或有显式说明。
