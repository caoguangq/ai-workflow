# Node 服务规范（栈规范，可选启用）

> 本文件只写本栈特有的可执行契约。通用规则见 `generic/`。命令由 `profile.commands` 提供。

## 异步与错误

1. 异步边界必须显式处理拒绝：不得出现未捕获的 Promise rejection。
2. 回调风格 API 必须包装或统一改用 Promise，不得混用。
3. 事件处理器中的异常必须捕获并记录，不得让其逃逸到进程级。

## 进程与生命周期

1. 启动时校验必需配置，缺失则退出并给出可操作的提示。
2. 收到终止信号时，停止接收新请求、等待在途请求完成、释放连接，然后退出。
3. 长任务不得阻塞事件循环；CPU 密集操作需要拆分或移出主线程。

## 依赖与版本

1. 锁文件必须提交，且与 `package.json` 声明一致。
2. 新增依赖需说明用途与体积影响；能用现有依赖解决则不新增。
3. 不得依赖未声明的传递依赖。

## 输入边界

1. 所有外部输入（请求体、查询参数、环境变量、文件内容）在使用前校验。
2. 校验失败返回明确的结构化错误，不使用异常文本表示。
3. 文件路径、命令参数等拼接场景必须做转义或白名单校验。

## 质量检查

- [ ] 新增异步路径是否有拒绝处理。
- [ ] 启动配置校验是否覆盖新增项。
- [ ] 是否有未声明却使用的依赖。
- [ ] 外部输入是否全部经过校验。
