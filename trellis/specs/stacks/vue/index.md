# Vue 前端规范（栈规范，可选启用）

> 本文件只写本栈特有的可执行契约。通用规则见 `generic/`。命令由 `profile.commands` 提供。

## 组件边界

1. 页面组件负责路由参数、数据获取与布局；展示组件只接收 props 并发出事件。
2. 展示组件不得直接发起请求或读取全局状态。
3. 单个组件超过 300 行时，优先按职责拆分，而不是继续加条件分支。

## 状态管理

1. 服务端数据与客户端 UI 状态分开存放，不得混在同一个 store 中。
2. 派生状态用计算属性，不额外存一份可写副本。
3. store 的 action 是唯一修改入口，组件不得直接改 state。

## 类型契约

1. 接口返回结构必须有类型定义，禁止用 `any` 绕过。
2. 类型定义与后端契约一一对应；契约变更时，类型文件必须同步更新并在 PR 中标注。
3. 可选的接口字段在前端必须显式处理缺失情形。

## 交互与错误

1. 所有请求调用必须有三种状态：进行中、成功、失败。
2. 失败必须对用户可见，不得只写控制台。
3. 提交类操作需防重复提交，并在失败后保留用户已填内容。

## 质量检查

- [ ] 新增请求是否处理了失败与空数据。
- [ ] 是否存在 `any` 或未定义类型的凭据。
- [ ] 提交类按钮是否有防重复机制。
- [ ] 契约变更是否同步了类型定义。
